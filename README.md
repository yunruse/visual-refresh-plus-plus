# visual refresh++

This is a Discord theme that makes nicer some of the Visual Refreshes in Discord.

## Installation

It's possible to put the CSS as a `<style>` in the HTML, but it's far easier to use the URL,

```
https://raw.githubusercontent.com/yunruse/visual-refresh-plus-plus/refs/heads/production/discord.css
```

as a theme in [Vencord](https://vencord.dev) or [BetterDiscord](https://betterdiscord.app). I prefer Vencord personally, but this should work in anything that styles Discord.
